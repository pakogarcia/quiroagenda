# **App Name**: QuiroAgenda

## Core Features:

- Appointment Entry: Add new appointments with client details (name, contact information, notes).
- Calendar View: Display the schedule in a daily or weekly calendar view.
- Appointment Management: Modify or delete existing appointments.
- WhatsApp Reminders: Send appointment reminders via WhatsApp 24 hours before the scheduled time. The tool should reason to check to verify reminders have not already been sent for the given appointments, before queing new reminders.

## Style Guidelines:

- Primary color: Soft green (#A7D9A9) to evoke relaxation and nature.
- Background color: Very light desaturated green (#F0FAF0).
- Accent color: Muted teal (#70A4A1) to add a touch of sophistication.
- Body and headline font: 'PT Sans' (sans-serif) for a modern and readable style.
- Use simple and clean icons related to massage therapy and appointment management.
- Clean and intuitive layout for easy navigation and appointment management.
- Subtle transitions and animations to enhance user experience.
